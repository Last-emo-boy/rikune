## Recommended Wave 3: Functional Worker/Parser Depth

- `linux-binary` (0.9): 为 `linux.binary.inventory` 增加无外部依赖的 ELF loader/security profile：输出 entrypoint、interpreter、needed libraries、rpath/runpath、NX stack candidate、RELRO candidate、bind-now candidate、canary symbol candidate，并用 conservative confidence/`*_candidate` 命名避免过度承诺。
- `wabt` (0.9): 修正并验证 `wabt.toolchain.run` 的 external worker contract：新增一个只读 WABT wrapper，使用 `WABT_WORKER_PATH` 作为可 spawn worker 命令，使用 `WABT_PATH` 查找 WABT binaries；最小支持 validation、objdump summary、WAT preview，返回结构化 `WorkerResult`，并保留 builtin fixture-safe 默认路径。
- `remill` (0.89): 先做 “bounded target enforcement” 小迭代：`remill.lift.run` 在 builtin/external 前都要求明确 function/address/range 目标，拒绝空目标和 whole-program/unbounded 目标，并在结果/错误中保留 policy reason。
- `apk-smali` (0.88): 让 `apk.disassemble` 正确覆盖 apktool 输出的所有 `smali*` 目录，并在结果中保留 multi-dex 分组/计数；这是最小但高价值的能力补强，能直接减少二级 DEX 漏报。
- `jsir-cascade` (0.88): 实现“输入感知但仍完全静态”的 `jsir-cascade` external worker v1：只读本地 JS/HTML/source-map 输入，受大小和超时限制，输出 digest、lexical metrics、dispatcher_model、handler_candidates、ir_nodes、warnings、static_only；不 eval、不启动浏览器、不访问网络、不写样本。builtin safe mode 保持 fixture 合约不变。
- `kb-collaboration` (0.88): 修复并深化 `kb.function.match` 的默认 KB 复用路径：当未提供 `match_against` 时，从 `function_kb` 加载参考知识进行匹配，返回来源、置信度、match reasons 和低置信过滤结果；保留显式样本匹配现有行为。
- `restringer` (0.88): 实现一个最小 no-eval 静态 REstringer wrapper 摘要：external wrapper 读取受限 JS 文件，识别 string-array literal、疑似 decoder function/call、简单 constant expression 候选，返回兼容旧字段的结构化 `restringer_deobfuscation_result`。
- `triton` (0.88): 为 `triton.symbolic.slice` 增加“外部模式必须有 bounded target”的可测试安全契约，并顺手补充最小搜索别名（opaque predicate、api resolver、keygen、path constraints）但不接入真实 Triton 后端。
- `jsvmp-analysis` (0.87): 实现一个只读、bounded、fixture-backed 的 JSVMP static scanner worker：external worker 读取本地 JS 文件，输出 bytecode array candidates、dispatcher model、handler map candidates、confidence breakdown、input budget/policy；builtin fixture 继续安全可用。
- `debug-session` (0.86): 优先把 `debug.session.snapshot` 做成真实 active-session 只读快照：session 不存在时失败；存在时采集 registers、stack、disasm 和用户指定 memory dumps；memory map/modules 先 best-effort，保留清晰 warnings。这个迭代直接把一个已暴露但占位的能力变成可用能力，风险和改动面都可控。
